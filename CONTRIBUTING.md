# Contributing to TORFA

First off, thank you for considering contributing to the Transparent Order Routing Fairness Analyzer (TORFA)! 

## How Can I Contribute?

### Reporting Bugs
If you find a bug in the source code, you can help us by submitting an issue to our GitHub Repository. Even better, you can submit a Pull Request with a fix.

### Submitting a Pull Request (PR)
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/AmazingFeature`).
3. Make your changes in your local environment.
4. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
5. Push to the branch (`git push origin feature/AmazingFeature`).
6. Open a Pull Request.

### Development Setup
Please refer to the `README.md` for full installation and local development instructions. 

### Coding Standards
*   Use ES6 syntax (Arrow functions, Destructuring, async/await).
*   Follow the existing directory structure (MVC for backend).
*   Ensure all data flowing from frontend to backend is sanitized and validated.
*   Document complex algorithmic changes within the backend services (`fairnessService.js`).
